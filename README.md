# AI-Citizen-Science
EPICS group for AI and citizen science that is working on app development for a game-style application that utilizes images of natural things.

## SETUP
Download the "Expo Go" mobile app (has a white A logo with a grey dot on the side)<br/>
Download and install VS Code: "https://code.visualstudio.com/download"<br/>
Download and install Git: "https://git-scm.com/install/"<br/>
Download and install Node.js: "https://nodejs.org/en/download" (verify by running "npm -v" in terminal)

### SETUP WITH GITHUB DESKTOP
Download GitHub Desktop<br/>
Sign in with GitHub account

### OPTION 1
Go to "https://github.com/EnnJayWithAGreyHat/AI-Citizen-Science"<br/>
Click the "Code" dropdown<br/>
Click "Open with GitHub Desktop"<br/>
Press Ctrl+Shift+A OR at the top, click Repositories --> Open With... and select Visual Studio Code<br/>
At the top, click Terminal --> New Terminal OR Ctrl+Shift+`<br/>
In the terminal, run "cd frontend/app"<br/>
In the terminal, run "npm i -g pnpm"<br/>
In the terminal, run "pnpm add expo"<br/>
In the terminal, run "pnpm expo start"<br/>
Scan the QR code!<br/>

#### OPTION 2
File --> Clone Repository<br/>
Click the URL option<br/>
Put "https://github.com/EnnJayWithAGreyHat/AI-Citizen-Science.git" into the top "URL" field<br/>
Choose a local path (recommended: C:\Users\name\OneDrive\Documents\GitHub) to put in the bottom field; this is where the actual code files will live<br/>
Select the project from the top-left dropdown arrow if not already selected<br/>
Press Ctrl+Shift+A OR at the top, click Repositories --> Open With... and select Visual Studio Code<br/>
At the top, click Terminal --> New Terminal OR Ctrl+Shift+`<br/>
In the terminal, run "cd frontend/app"<br/>
In the terminal, run "npm i -g pnpm"<br/>
In the terminal, run "pnpm add expo"<br/>
In the terminal, run "pnpm expo start"<br/>
Scan the QR code!<br/>

### STAYING UPDATED
In GitHub Desktop, there is a "Pull Origin" button near the top left. Click that when you want the most recent version of our changes!
