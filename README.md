# AI-Citizen-Science
EPICS group for AI and citizen science that is working on app development for a game style application that utilizes images of nature things

### SETUP
Download the "Expo Go" mobile app (has a white A logo with a grey dot on the side)
Download and install VSCode: "https://code.visualstudio.com/download"
Download and install Git: "https://git-scm.com/install/"
Download and install Nodejs: "https://nodejs.org/en/download" (verify by running "npm -v" in terminal)
#### SETUP WITH GITHUB DESKTOP
Download GitHub Desktop
Sign in with github account
##### OPTION 1
Go to "https://github.com/EnnJayWithAGreyHat/AI-Citizen-Science"
Click the "Code" dropdown
Click "Open with GitHub Desktop"
Press Cntrl+Shift+A OR on the top click Repositories --> Open With... and select Visual Studio Code
On the top click Terminal --> New Terminal OR Cntrl+Shift+`
In the terminal, run "cd frontend/app"
In the terminal, run "npm i -g pnpm"
In the terminal, run "pnpm add expo"
In the terminal, run "pnpm expo start"
Scan the QR Code!
---
##### OPTION 2
File --> Clone Repository
Click the URL option
Put "https://github.com/EnnJayWithAGreyHat/AI-Citizen-Science.git" into the top "URL" feild
Choose a local path (reccomended: C:\users\<your name>\OneDrive\Documents\GitHub) to put in the bottom field, this is where the actual code files will live
Select the project from the top left drop down arrow if not already selected
Press Cntrl+Shift+A OR on the top click Repositories --> Open With... and select Visual Studio Code
On the top click Terminal --> New Terminal OR Cntrl+Shift+`
In the terminal, run "cd frontend/app"
In the terminal, run "npm i -g pnpm"
In the terminal, run "pnpm add expo"
In the terminal, run "pnpm expo start"
Scan the QR Code!
